# Bitácora de clases — Bootcamp AI Engineer (4Geeks)

Notas de cada día de clase: instrucciones dadas, conceptos relevantes, recursos, dudas y deberes.

**Días de clase:** lunes, miércoles y viernes. Duración: 24 semanas (inicio: 13 jul 2026).

## Cómo usarla

- Cada semana tiene su carpeta `semana-NN/`.
- Cada día es un archivo `AAAA-MM-DD-dia.md`.
- Para crear un día nuevo, copia [`_plantilla.md`](./_plantilla.md) y renómbralo con la fecha.
- Añade el enlace del día nuevo a la tabla de abajo.
