# Archivo de contextos de empresa

Copia de referencia de los briefings de las **cuatro empresas** del track de AI Engineering de 4Geeks Academy. Se guardan aquí para poder comparar dominios entre empresas, aunque este proyecto trabaje solo con una.

## Empresa activa de este repo

**Nexova Solutions** — consultora de RR. HH. y selección de talento (Valencia, España + Miami, Florida).

El briefing activo (fuente única de verdad del proyecto) vive en la **raíz** del repo:

- [`CONTEXT.md`](../../CONTEXT.md) — inglés
- [`CONTEXT.es.md`](../../CONTEXT.es.md) — español

Ambos son copia de `CONTEXT-nexova-briefing.{en,es}.md` de esta carpeta. Si actualizas el briefing, actualiza también los de la raíz.
